# Todo-лист (Консольное приложение)

Простое консольное приложение для управления списком задач, написанное на Pascal (PascalABC.NET).

## Как запустить

1. **Интерактивный режим (Меню):** 
   запустите файл `TodoList.exe` двойным кликом.
2. **Режим командной строки (CLI):**
   Откройте терминал в папке с программой и используйте команды:
   - `TodoList.exe add "Название задачи"`
   - `TodoList.exe list`
   - `TodoList.exe done <номер>`
   - `TodoList.exe undone <номер>`
   - `TodoList.exe delete <номер>`
   - `TodoList.exe clear`
   - `TodoList.exe stats` (дополнительная функция: статистика)
   - `TodoList.exe search <ключевое слово>` (дополнительная функция: поиск)
  
   Если вы используете PowerShell вместо стандартной командной строки (cmd), перед именем исполняемого файла обязательно добавляйте .\ (например: .\TodoList.exe) 
  
## Реализованный функционал

### Базовый:
- **`add <название>`** — добавить новую задачу.
- **`list`** — вывести все задачи с их порядковыми номерами и текущим статусом.
- **`done <номер>`** — отметить задачу как выполненную.
- **`undone <номер>`** — вернуть выполненную задачу в статус «не выполнена».
- **`delete <номер>`** — удалить задачу по номеру.
- **`clear`** — полностью очистить список выполненных задач (с обязательным подтверждением действия).

### Дополнительный:
- **`stats`** — вывод краткой статистики (всего задач, выполнено, не выполнено).
- **`search <ключевое слово>`** — поиск задач по названию (без учета регистра).

## Формат хранения данных

Данные хранятся в текстовом файле `tasks.txt` в кодировке UTF-8. 
Каждая строка файла представляет одну задачу и имеет следующий формат:

```text
СТАТУС|НАЗВАНИЕ_ЗАДАЧИ
```
